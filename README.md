# 🙏 Projeto Carlo Acutis - Primeiro Santo Millennial

## 📌 Sobre o Projeto

Este é um site informativo desenvolvido para a disciplina de **Tecnologia Web**, com o objetivo de apresentar a vida, o legado e a canonização de **Carlo Acutis**, o primeiro santo da geração millennial. O projeto explora conceitos fundamentais de desenvolvimento web utilizando **HTML5** e **CSS3**, com foco em design responsivo, acessibilidade e organização de conteúdo.

### 🎯 Objetivos do Projeto

- ✅ Aplicar conceitos de **HTML semântico** e **CSS moderno**
- ✅ Desenvolver um site com **múltiplas páginas** interligadas
- ✅ Implementar **design responsivo** para diferentes dispositivos
- ✅ Utilizar **boas práticas** de organização de código e estrutura de pastas
- ✅ Criar uma **experiência visual agradável** e coesa

## 📱 Páginas do Site

### 1️⃣ **Início (index.html)**
- Apresentação do projeto
- Cards com links para as demais páginas
- Design clean e convidativo

### 2️⃣ **Biografia (biografia.html)**
- Nascimento e infância em Londres
- Descoberta da fé e Primeira Comunhão
- Adolescência e hobbies
- Doença e falecimento aos 15 anos

### 3️⃣ **Legado (legado.html)**
- O "Programador de Deus" e o site dos Milagres Eucarísticos
- Frases famosas de Carlo
- Milagres reconhecidos (Brasil e Costa Rica)

### 4️⃣ **Canonização (canonizacao.html)**
- Processo de beatificação e canonização
- Cerimônia no Vaticano
- Túmulo em Assis e devoção popular
- Mensagem para os jovens

## 🎨 Design e Estilo

### Paleta de Cores
| Cor | Uso |
|-----|-----|
| `#1a1a2e` | Fundo escuro (cabeçalho, rodapé, botões) |
| `#c9a94e` | Destaques dourados (subtítulos, bordas) |
| `#f5f7fa` | Fundo claro do conteúdo |
| `#ffffff` | Fundo dos cards e seções |

### Tipografia
- **Fonte Principal:** [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)
- **Pesos:** 400 (regular), 500 (medium), 700 (bold)

### Responsividade
O site se adapta a diferentes tamanhos de tela:
- 📱 **Mobile:** Layout em coluna única
- 💻 **Desktop:** Cards lado a lado
- 📐 **Breakpoint:** 768px
